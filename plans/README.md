## Findings considered and rejected

- **Embedding a full Node.js + NPM distribution into a standalone APK**: Rejected due to 80MB+ binary footprint and Android Bionic libc incompatibilities. The headless Termux background engine (Plans 001 & 002) provides full toolchain access with 0 added disk footprint.
- **Auto-spawning X11/VNC desktop server**: Rejected as contrary to AGY Online's sub-15MB idle RAM architectural principle. The WebGL + PWA browser interface covers all development needs.
